# tinyGPT

A tiny GPT decoder to learn how transformers work. The project was made by following Attention Is All You Need, OpenAI's GPT-2, and some karpathy videos.

It trains on `input.txt`, the works of Shakespeare, and turns raw characters into a next-token predictor.

## What’s inside

- a small GPT built from scratch
- self-attention, multi-head attention, feed-forward blocks, residual connections, layernorm, and dropout
- a Shakespearean training set


I would not recommend running the training cell unless you have a decent gpu and 40 or more minutes. :)
